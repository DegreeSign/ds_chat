Reading the map

Bands run top to bottom in dependency order: the host passes one ChatInput or a smaller ChatPreloadInput, createChat binds its callbacks to the shared runtime, resolves the host tools and the built-ins into one list, the runtime lazily imports an engine, and the engine streams the reply or runs a tool round. Hover brightens one function and its neighbours, click pins it, and the panel lists every caller and every callee plus the shortest path back to the public entry.
