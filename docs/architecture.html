Reading the map

Bands run top to bottom in dependency order: the host passes one ChatInput, a smaller ChatPreloadInput or a DescribeImagesInput, createChat binds its callbacks to the shared runtime, the runtime lazily imports an engine, and the engine streams the reply back. describeImages loads the vision model, then the GPU translator when the target is not English, reporting each model through onStatus. clearModelCache releases the model and deletes every stored file. Hover brightens one function and its neighbours, click pins it, and the panel lists every caller and every callee plus the shortest path back to the public entry.
